WHAT IS GTFS
The standard,
parsed properly

GTFS (General Transit Feed Specification) is the standard transit agencies use worldwide to publish schedule and live vehicle data — the same format behind Google Maps and most trip planners. This project parses it directly: no database, no caching layer, just a C++ library scanning the raw GTFS Schedule .txt tables and GTFS Realtime .pb protobuf feeds and answering queries straight off them.

STATIC-GTFS
gtfs.hpp — a single ~1,900-line C++17 header, zero external deps. Parses routes, stops, trips, calendars, shapes and fares straight from GTFS Schedule .txt files.
GTFS-RT
C++ tools built on protobuf that decode GTFS Realtime .pb feeds — trip updates, vehicle positions, service alerts — into JSON.
WEBSERVER
A Flask app that shells out to the compiled C++ tools and serves a vanilla-JS frontend as a REST API. Ships a token-gated variant for exposing it beyond localhost.
VERSIONS
